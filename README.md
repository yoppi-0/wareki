# wareki
![test](https://github.com/yoppi-0/wareki/actions/workflows/test.yml/badge.svg)

標準入力から読み込んだ西暦を和暦に変換し標準出力に出力する。

## インストール

```
$ git clone https://github.com/yoppi-0/wareki.git
$ cd wareki
```

## 使用方法
- 一行に一つの西暦を入力します。

```
$ echo 2007 | ./wareki
平成19
```

- 複数の西暦をまとめて変換することも可能です。

```
$ seq 1985 1990 | ./wareki
昭和60
昭和61
昭和62
昭和63
平成1
平成2
```

1989年のように元号が変わった年は、新しい元号で出力します。

## 入力の条件
- 数値（整数）を受け付けます。
- 数値の対応範囲は1868から実行した時の西暦です。
- 数値でない値が入力された場合、もしくは対応範囲外の整数か整数以外の数値が入力された場合エラーメッセージを標準エラー出力に出し、終了ステータス1で終了します。

```
$ echo あ | ./wareki
西暦の年を整数で入力してください
$ echo $?
1
```
