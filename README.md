# wareki
![test](https://github.com/yoppi-0/wareki/actions/workflows/test.yml/badge.svg)
標準入力から読み込んだ西暦を和暦に変換し標準出力に出力する

##インストール
$ git clone https://github.com/yoppi-0/wareki.git
$ cd wareki

## 必要なソフトウェア
- Python
  - テスト済みバージョン: 3.10〜3.14

## テスト環境
- Ubuntu 24.04 LTS
